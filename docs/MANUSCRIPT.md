# 논문 작성 노트

**작업 제목** — *Accuracy and computational cost of teacher-to-student distillation for sEMG-based elbow angle estimation across six model families*

## 연구 질문

sEMG로 팔꿈치 각도를 추정할 때, 같은 계열의 큰 모델에서 작은 모델로 예측값을 증류하면 정답만 학습한 작은 모델보다 오차가 감소하는가? 큰 모델과 비교했을 때 추론 시간과 파라미터 수는 얼마나 줄어드는가?

## 방법에 쓸 내용

1. **자료와 입력** — Mechtenberg 등(2023)의 공개 데이터에서 30명을 개발에 사용했다. 이두근과 삼두근의 네 채널에서 RMS, 평균 절댓값, 인접 샘플 변화량의 평균 절댓값을 만들고 로그 변환했다. 각 입력은 100ms 간격으로 현재까지의 21개 특징 벡터를 사용한다. 입력의 정확한 단위와 순서는 [특징 정의](../semg_distillation_study/FEATURE_CONTRACT.md)에 있다.
2. **비교 모델** — GRU, MLP, Transformer, LSTM, TCN, CNN1D 각각에서 큰 교사, 작은 직접, 작은 증류 모델을 비교했다. 작은 두 모델의 구조는 같고 분할과 seed별 초기화 및 배치 순서가 일치한다. 직접 모델은 정답 각도를, 증류 모델은 정답 각도와 해당 교사의 예측값을 같은 비중으로 맞추도록 학습했다.
3. **개발 평가** — 피험자 단위 다섯 분할마다 24명 학습과 6명 평가를 수행했다. 학습 집단에서 정규화 값을 계산했다. 학생은 세 초기값으로 반복했고 교사는 분할별 고정 가중치를 사용했다. 사람별 MAE와 RMSE, 직접 대비 증류의 짝지은 MAE 차이, 파라미터 수, CPU 추론 시간을 보고한다.
4. **시간 측정** — CPU 4스레드, float32, 배치 1에서 각 체크포인트에 예열 30회와 측정 200회를 적용했다. 교사 학습, 교사 예측 생성, 학생 학습 비용을 별도 제시한다.

## 현재 결과에 쓸 내용

GRU 증류 학생의 MAE가 18.155°로 6종 중 가장 낮았다. Transformer 학생은 직접 학습 18.763°에서 증류 18.401°로 평균 0.362° 개선됐다. 30명 중 23명에서 오차가 감소했고, 6개 비교를 보정한 조건부 구간은 +0.030°~+0.692°였다. TCN은 평균 오차가 0.007° 늘었다. 모델별 MAE와 RMSE, 조건부 구간, 속도는 [6종 결과 보고서](../results/six-family/README.md)에 정리했다.

## 해석과 남은 실험

- 평균 MAE는 약 18°이고 최대 개선은 약 0.36°다. 목표 용도에서 이 변화량이 충분한지 별도 기준으로 판단한다. 개발 분할을 체크포인트 선택과 점수 계산에 함께 썼으며, 보정 구간도 고정 교사와 개발 자료에 조건부다.
- 작은 모델의 추론 속도와 증류가 추가한 정확도 이점을 각기 다른 비교로 해석한다. 시간은 특정 CPU 환경의 측정이고 기록된 학습 단계에는 병렬 실행의 영향이 있다.
- 최종 설계는 **30명 전체 학습 → 별도 피험자 10명·20명 평가**다. 공통 주 비교, 가중치, 학습 길이 결정 규칙, 평가 집단과 지표를 사전에 확정한다. 여섯 모델의 최종 학습을 마치고, 호환되는 새 피험자에서 같은 저장 모델을 비교한다. 두 평가 집단의 관계와 포함 기준도 먼저 문서화한다.

원본 데이터 출처는 [Mechtenberg 등(2023) 공개 데이터](https://www.hsbi.de/publikationsserver/record/2290)다.
